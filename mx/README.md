The Osprette MX
===============

An MX-switch version of the [Osprette](../v1). Same 34-key unibody layout with
pinky clusters, but laid out for MX switches instead of choc. The case files are
in the `case` folder.

The split version of this board is [the Sephirette][sephirette].


[sephirette]: https://github.com/smores56/sephirette
